ARCHITECTURE

技術構成

iPhoneアプリは「話す・聞く」に徹し、開発の実行と読み上げ文の生成はPC側のサーバーが担当します。

iPhoneアプリ（SwiftUI）
  • 音声区間検出（VAD）で発話の開始・終了を判定
  • 音声認識（STT）で発話を文字に変換
  • 読み上げ（TTS）で結果を音声で返す
  • 会話状態の管理（割り込み・停止に対応）
PC常駐サーバー（Bridge）
  • WebSocketでiPhoneと常時接続
  • Claude Code CLI と連携して開発を実行
  • 進捗イベントを解析し、読み上げ文を生成
  • セッションとプロジェクトの切り替えを管理
🪟 Windows PC 🍎 Mac / Xcode 📱 iPhone / Simulator

※ PCの画面・キーボード・マウスをエミュレートする方式は採っていません。CLIと直接連携することで、 画面の状態に左右されず安定して動作させています。
